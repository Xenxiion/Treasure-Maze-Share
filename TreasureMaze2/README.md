# TreasureMaze - The Last Symbol (Java 21 Swing)

Build (project root):  mkdir out && javac -d out $(find src -name '*.java')
Run (project root):    java -cp out Main
Keys: WASD/arrows move, R restart level (-1 heart), M mute.

Rules: see the in-game HOW TO PLAY screen. Maps are generated randomly and validated on every new game.
Assets and licenses: assets/CREDITS.md. Project state and limitations: HANDOFF.txt.
