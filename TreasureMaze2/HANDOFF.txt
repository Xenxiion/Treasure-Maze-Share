TEST TIMEOUT NOTE
- The full-game headless test (reflection harness G.java in the session scratchpad) hit the 120 s tool limit (exit code 143). Cause: the test created a JFrame under java.awt.headless=true (HeadlessException) and the non-daemon javax.swing.Timer in TreasureMaze kept the JVM alive, so System.exit was never reached. After removing the JFrame the test finished with fails=0. Always run with timeout and System.exit.
